# Redux Concpets

1. Store: Central location contains application state
2. Action: Describe what happened
3. Reducer: its a function which updates the state based on action
4. Dispatch: send the created action to Redux
5. Selector: Reads data from Redux
6. Slice: Defines a perticular part of the state and its reducers.
