## Create Express & Pug project

- create folder express-pug-demo
- move to the folder -> cd express-pug-demo
- package.json -> npm init -y
- edit package.json: "type": "module",
- install : npm i express pug
- npm install --save-dev nodemon
- create views folder - create file index.pug under that
- add code in index.pug
- create app.js, add code
- run using node app.js
- check output localhost:3000 in browser
