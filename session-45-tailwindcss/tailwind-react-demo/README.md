# React with Tailwind CSS

## Basic Styling

- for text coloring - text-*, eg. text-blue-600
- Spacing: Margin & padding
  -  m (margin)
  -  p (padding)
  -  mt (margin-top), mb (margin-bottom)
  -  my (margintop+margin bottom)
  -  mx (margin left & margin right)
- w - width
- h - height
- bg - background
- rounded-* (xl, md, sm)
- shado-* (xl,md,sm)

## Think about flexbox (flex)

- class flex, items-center, justify-center
