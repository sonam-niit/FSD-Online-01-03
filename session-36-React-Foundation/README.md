# Create React App using Vite

[Documentation Link](https://vite.dev/guide/)

```bash
npm create vite@latest
#  prompt for vite version say yes and continue
#  ask for app name enter first app
#  select variant React
#  language: TS
# continue with default Oxlint
# do you want to install packages and start app if you say yes it will install all packages and start app
#  here if you say no then you need to execute below stpes

cd firstapp
npm install # download all required dependencies (needs to execute only once)
npm run dev # start development server
# access app http://localhost:5173/
# stop using ctrl+c 
```
