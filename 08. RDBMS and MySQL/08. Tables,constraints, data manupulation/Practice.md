# Blogging App – SQL Practice Task

You are going to build a simple Blogging Application database using MySQL.

In this task, you will practice:

1. CREATE
2. ALTER
3. INSERT
4. UPDATE
5. DELETE
6. SELECT
   
## Execution steps

1. Create Database (blogging_app)
2. Create Users Table: users
   - user_id (INT)
   - first_name
   - last_name
   - email
   - city
3. Add More Columns (Alter)
   - phone
   - created_at (date by default it will go current)
   - membership_fee
4. Insert Users (insert 5 records)
   - insert 2 as single record
   - insert 3 as multi record
5. Create Posts Table:
   - post_id
   - title
   - content
   - author_id
   - category
   - created_at
6. insert Records (5)
7. try to update some records
8. 1-2 delete queries.
